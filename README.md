# The Gold Is Too Heavy

Godot starter project for the game jam.

## Getting started

1. Clone this repository.
2. Open Godot 4.6 and import `project.godot`.
3. Open the project and press **F6** with `main_scene.tscn` open, or **F5** to run the project.

The starting scene is an empty `Node2D`, so running the project displays a blank window until game content is added. The project uses the GL Compatibility renderer.

## Version control

Commit project files, scenes, scripts, and source assets. Godot's generated `.godot/` cache is excluded from Git and recreated when the project is opened.
