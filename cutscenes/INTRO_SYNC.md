# Начальная катсцена: субтитры и свет

Открой `res://scenes/intro.tscn` и нажми **F6**. Кнопка **PLAY** на старом стартовом экране тоже запускает эту сцену; после окончания записи и затемнения открывается розовое меню `res://scenes/main_menu.tscn`. Его кнопка **LET'S PLAY!** начинает игру без повторного просмотра катсцены.

Аудио: `res://cutscenes/audio/intro_voice.ogg`. Это версия исходной записи `17.10.2026 16.46.m4a` в формате для Godot, без изменения скорости или обрезки. Продолжительность — около 42,52 секунды. Исходный файл сохранён.

## Как синхронизировать субтитры

1. Открой `res://cutscenes/scenes/intro_subtitles.json` в текстовом редакторе. Начальные тайминги уже автоматически сопоставлены с записью; при необходимости подстрой их на слух.
2. У каждой реплики есть `start` — момент появления, `end` — момент исчезновения и `text` — текст. Время задаётся в **секундах от начала аудио**, с точкой: `4.05`, а не `4,05`. Пример:

   ```json
   {
     "start": 4.05,
     "end": 6.68,
     "text": "I refuse to accept it. It doesn't make any sense."
   }
   ```

3. Чтобы строка появлялась раньше, уменьши `start`; чтобы оставалась дольше, увеличь `end`. `end` должен быть больше `start`. Реплики должны идти по времени и не пересекаться. Между репликами надпись исчезает.
4. Сохрани файл и перезапусти сцену. Для быстрой проверки выбери корневой узел **Intro → Playback → Start Time**, например `38`, и нажми **F6**: запись начнётся с этой секунды, свет и субтитры сразу окажутся в нужном состоянии. После настройки верни **Start Time = 0**.
5. Если все строки сдвинуты одинаково, меняй **Intro → Subtitles → Subtitle Offset Seconds**. Положительное значение задерживает их, отрицательное показывает раньше. Например, `0.2` задержит все строки на 0,2 секунды. Точку света, привязанную к реплике, этот сдвиг тоже передвигает.
6. **Playback → Log Subtitle Times** выводит в панель Output время смены каждой реплики. Звук и субтитры используют одну временную шкалу с компенсацией задержки аудиовыхода.

Длинный текст переносится автоматически. Для ручного переноса используй `\n` внутри `text`. Субтитры — простой белый текст снизу экрана, без подложки. Шрифт, размер и положение меняются у **Subtitles/Text**.

## Когда включается передний свет

В исходном тексте нет дословной фразы «you know who I am». Последние две строки — «You wondering who I am?» и «I think you already know.». Вторая начинается на **40,85 с**, у неё в JSON стоит `"reveal": true`. Перед раскрытием добавлена пауза **Reveal Delay = 1 с**: свет начинает включаться на **41,85 с** и полностью проявляет персонажа к **42,30 с**.

Чтобы выбрать другую реплику, перенеси `"reveal": true` к ней, убрав его у прежней. Свет плавно включится через **Reveal Delay** после её `start`, с учётом общего сдвига субтитров. Используется первая реплика с этой отметкой.

Для точного момента внутри фразы задай **Intro → Front Light → Reveal Time Override**, например `41.1`. Это абсолютное время аудио; общий сдвиг субтитров и **Reveal Delay** на него не влияют. Значение `-1` возвращает привязку к отмеченной реплике.

**Reveal Duration** — длительность включения света; **Front Light Energy** — яркость. Свет — настоящий узел **FrontLight (PointLight2D)**. До его включения **Darkness (CanvasModulate)** оставляет картинку чёрным силуэтом.

После полного раскрытия персонаж остаётся видимым **1 секунду** (**Intro → Ending → Ending Hold Duration**), затем плавно затухает за **0,7 секунды** (**Ending Fade Duration**). При текущих таймингах затухание идёт примерно с **43,30 до 44,00 с**, после чего открывается меню. Окончание аудио не обрывает раскрытие и паузу; если запись длиннее, переход также дождётся её окончания.

**Intro → Character Shading → Side Shadow Strength / Bottom Shadow Strength** управляют мягким затемнением картинки по бокам и снизу. Значение `0` убирает соответствующую тень. Затемнение не затрагивает субтитры и фон.

## Остальные настройки

- **Intro → Back Light**: цвет и яркость очень тёмного заднего свечения, частота и глубина пульсации. **Pulse Frequency** — число пульсаций в секунду.
- **Camera2D → Pixel Size**: лёгкая пикселизация, по умолчанию `2`. Она масштабируется вместе с окном; `1` отключает эффект.
- **Intro → Playback → Fade Duration**: длительность появления сцены. Финальное затухание настраивается отдельно в **Ending**.
- **Voice → Stream**: аудиодорожка. При её замене обнови тайминги в JSON и верни **Start Time** в `0`.

JSON, аудио и картинка подключены к сцене как ресурсы и включаются при экспорте зависимостей сцены. `startcutscenesubtitles.txt` — исходный текст; изменение этого TXT не меняет готовые субтитры, редактируй JSON.
